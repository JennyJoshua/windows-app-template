# Windows Application Customization Template

A reusable template for customizing open-source Windows applications
with personal branding, application renaming, and minor modifications.

## Objectives

- Rebrand applications with custom names and logos.
- Make small changes to existing features and appearance.
- Preserve the original application's functionality.
- Build Windows applications using GitHub Actions where supported.
- Download build artifacts without requiring a local development computer.

## Workflow

1. Identify a suitable open-source Windows application.
2. Review its licence and redistribution requirements.
3. Create a new repository from this template.
4. Import the original application's source code.
5. Configure the application name, logo, and icons.
6. Apply approved customizations.
7. Build and test the application.
8. Download the resulting executable or installer.

## Important Requirements

- Prefer free tools and GitHub cloud builds.
- Do not assume every application supports the same build process.
- Preserve required copyright notices and licence files.
- Never commit passwords, API keys, or other secrets.
- Do not overwrite the original source until its licence and build
  requirements have been reviewed.
